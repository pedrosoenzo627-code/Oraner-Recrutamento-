# Contato institucional — Cumbuca Dev

Este documento prepara uma primeira conversa para apresentar a Oraner e pedir orientação. **Não é uma candidatura a um programa confirmado nem um pedido para divulgar vagas sem remuneração.**

## Contexto verificado

A página [Para Empresas da Cumbuca Dev](https://cumbuca.dev/para-empresas/) apresenta o Cumbuca Conecta como uma solução para divulgar vagas e orientar pessoas candidatas para oportunidades. A página não confirma que divulgue oportunidades não remuneradas.

A página [Apoie](https://cumbuca.dev/apoie/) também descreve iniciativas da comunidade relacionadas a código aberto, mentoria, participação em repositórios e parcerias. Por isso, a pergunta mais adequada é se há orientação, iniciativa educacional ou forma de apresentar um projeto open source em fase inicial.

## Mensagem preparada

**Assunto: Apresentação da Oraner Technologies e consulta sobre código aberto**

Olá, equipe da Cumbuca Dev!

Meu nome é [NOME] e estou desenvolvendo a Oraner Technologies, uma iniciativa de tecnologia em fase inicial.

Estamos organizando projetos de software e pesquisa, incluindo:

- **OraOS 1:** sistema para smartphones baseado no Android Open Source Project (AOSP).
- **OraBook OS:** projeto de sistema operacional para computadores baseado em Linux.
- **OnWea:** ideia de plataforma de software para dispositivos vestíveis, ainda em avaliação.
- **OraStore:** conceito de catálogo e distribuição de aplicativos.
- **OraCam:** aplicativo de câmera para Android.
- **OraCloud:** iniciativa de serviços em nuvem, ainda em planejamento.
- **OraUI:** identidade visual e sistema de interface.

Estamos documentando as tecnologias, os objetivos e as limitações de cada projeto. Ainda não temos orçamento para contratações ou salários e não queremos anunciar oportunidades de trabalho sem remuneração.

Gostaríamos de saber se a Cumbuca Dev oferece orientação, iniciativas educacionais, mentoria ou possibilidades de parceria relacionadas a projetos independentes de código aberto em fase inicial.

Também gostaríamos de perguntar:

1. Existe algum programa ou atividade da Cumbuca Dev adequado para conhecer boas práticas de projetos open source?
2. A comunidade permite que projetos externos apresentem uma iniciativa para receber orientação técnica ou educacional?
3. Quais são os critérios para uma possível parceria ou participação?
4. Existe uma pessoa ou canal indicado para conversar sobre esse tipo de iniciativa?
5. Há algum requisito de formalização ou documentação que deveríamos conhecer antes de avançar?

A Oraner está em fase de organização e queremos conduzir qualquer aproximação com transparência, respeito à comunidade e atenção às responsabilidades legais. Como sou menor de idade, as conversas institucionais e qualquer proposta formal serão acompanhadas por meu responsável legal.

Agradeço pela atenção!

Atenciosamente,

[NOME]  
Idealizador da iniciativa Oraner Technologies  
Repositório informativo: https://github.com/pedrosoenzo627-code/Oraner-Recrutamento-

## Antes de enviar

- Peça ao seu responsável para revisar e acompanhar a mensagem.
- Use um e-mail de contato apropriado, com acompanhamento do responsável.
- Não envie documentos pessoais, dados bancários ou credenciais.
- Não descreva a Oraner como empresa formalmente constituída se isso não estiver confirmado.
- Não afirme que existe uma parceria com a Cumbuca Dev antes de receber confirmação por escrito.
